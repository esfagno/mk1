# Калькулятор на STM32 Nucleo-C031C6

Проект представляет собой простой калькулятор на микроконтроллере **STM32 Nucleo-C031C6**, реализованный на языке C в среде Wokwi.

Калькулятор выполняет четыре арифметические операции над двумя однозначными числами от 0 до 9. Ввод осуществляется с помощью матричной клавиатуры, а результат отображается на четырёхразрядном семисегментном дисплее TM1637.

## 1. Возможности проекта

- Ввод двух чисел от 0 до 9.
- Сложение.
- Вычитание.
- Умножение.
- Деление.
- Отображение результата на семисегментном дисплее.
- Обработка деления на ноль.
- Вывод отладочных сообщений через последовательный порт.
- Светодиодная индикация работы программы.

## 2. Используемые компоненты

| Компонент | Назначение |
|---|---|
| STM32 Nucleo-C031C6 | Основной микроконтроллер |
| Мембранная клавиатура 4×4 | Ввод чисел и выбор операции |
| Дисплей TM1637 | Отображение результата |
| Светодиод | Индикация работы программы |
| Резистор 1 кОм | Ограничение тока светодиода |

## 3. Подключение компонентов

### Матричная клавиатура 4×4

| Контакт клавиатуры | Контакт STM32 |
|---|---|
| R1 | PB7 |
| R2 | PB6 |
| R3 | PA10 |
| R4 | PB3 |
| C1 | PB10 |
| C2 | PB4 |
| C3 | PB5 |
| C4 | PB0 |

### Дисплей TM1637

| Контакт дисплея | Контакт STM32 |
|---|---|
| CLK | PA6 |
| DIO | PA7 |
| VCC | 3V3 |
| GND | GND |

### Светодиод

| Элемент | Подключение |
|---|---|
| Анод светодиода | PA5 |
| Катод светодиода | Через резистор 1 кОм к GND |

### Последовательный порт

| Контакт | Подключение |
|---|---|
| TX | PA3 |
| RX | PA2 |

## 4. Управление калькулятором

Используется стандартная раскладка матричной клавиатуры 4×4:

```text
1   2   3   A
4   5   6   B
7   8   9   C
*   0   #   D
```

Назначение клавиш:

| Клавиша | Действие |
|---|---|
| 0–9 | Ввод числа |
| A | Сложение (+) |
| B | Вычитание (-) |
| C | Умножение (*) |
| D | Деление (/) |
| # | Выполнение вычисления |
| * | Сброс текущего ввода |

## 5. Порядок работы

1. Запустить симуляцию в Wokwi.
2. Ввести первое число с помощью клавиатуры.
3. Нажать клавишу операции:
   - A — сложение;
   - B — вычитание;
   - C — умножение;
   - D — деление.
4. Ввести второе число.
5. Нажать `#` для выполнения вычисления.
6. Результат появится на дисплее TM1637.

Для начала нового вычисления можно нажать `*`.

**Важно:** при попытке деления на ноль программа выводит сообщение об ошибке `Err`.

## 6. Структура проекта

```text
project/
│
├── diagram.json    # Схема подключения компонентов Wokwi
├── main.c          # Главная программа и логика калькулятора
├── main.h          # Определения регистров и общие объявления
├── keyboard.c      # Реализация работы с клавиатурой
├── keyboard.h      # Заголовочный файл клавиатуры
├── tm1637.c        # Драйвер семисегментного дисплея
└── tm1637.h        # Заголовочный файл дисплея
```

## 7. Запуск проекта

1. Открыть проект в Wokwi.
2. Убедиться, что все файлы проекта добавлены в редактор.
3. Проверить соответствие соединений в `diagram.json` таблицам подключения.
4. Запустить симуляцию кнопкой **Start Simulation**.
5. Выполнить вычисление с помощью клавиатуры.

## 8. Используемые технологии

- Язык программирования C.
- Микроконтроллер STM32 Nucleo-C031C6.
- Среда моделирования Wokwi.
- Работа с GPIO через регистры микроконтроллера.
- Последовательный интерфейс USART.

- Протокол управления дисплеем TM1637.

В результате разработан калькулятор на базе STM32 Nucleo-C031C6, позволяющий выполнять четыре основные арифметические операции. Ввод данных осуществляется через матричную клавиатуру 4×4, а результат вычислений отображается на семисегментном дисплее TM1637.
